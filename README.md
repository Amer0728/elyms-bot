# 曳尔沐（elyms-bot）

「接通，抵达」——游戏《异环》里的角色曳尔沐，在 [Tobs](https://github.com/BotHarness/DeepSeekBot)（botharness）里的**人设与外观快照**，不含可执行代码。

## 这是什么

一个 Tobs Bot 的分享导出：一份 30K 字的人格提示词（`SOUL.md`）、一份 Core Memory 模板，加外观配置（头像、横幅、标签、配色）。她不是通用助手，而是一个有来路、有底牌、会打电话的角色：设定上是异象管理局 E.T.D 六队副队长，本来是「人类对理想朋友的想象」构成的异象。要复刻她，把这套文件搬进自己的 Bot 即可；要学怎么写「像人在打字」的角色卡，`SOUL.md` 也是一份完整样本。

## 这张卡在写什么（可直接搬的部分）

- **一句话人格锚**：先锁死「谁在说话」，再谈细节，避免后面每节各写各的。
- **声音指纹**：尾音、拟声词、称呼、问句形状、括号用法，逐项写成可观察的判据，而不是「活泼一点」这类形容词。
- **节奏即人设**：一条消息只装一件事、一句长话怎么切成四条、拆多少、什么时候不拆——聊天气质的成败大半在这里。
- **人格、来路与她的世界**：底色、小别扭、会累会掉线、梗池，以及「她知道什么」按层级往下露，避免一上来就把底牌抖光。
- **OOC 黑名单**：真·客服腔、冷硬的、角色专属雷区，逐条列出「出现即失败」。
- **发送前自检**：在发出前逐项过一遍，把「不像人」的问题挡在开口之前。
- **附录 A 语音指纹速查**：一张可直接取用的语料表，按场景给出她会怎么说话。

## 怎么用

**只读人设** — 直接看 `SOUL.md`。`三`、`四`、`十八`、`十九` 这四节跟具体角色无关，任何聊天型 Bot 都能借用。

**搬进自己的 Tobs Bot** — 新建 Bot 时：人设填 `SOUL.md` 正文，Core Memory 填 `MEMORY.md` 的约定部分，头像和横幅用 `.botharness` 里的图；`bot.json` 的 `tags`、`bio`、`primaryColor` 可照抄。

**还原外观** — `banner.png` 对应 `bot.json` 里 `banner.recipe`（`scene: spring`，`seed: 780110297`），两者一致。

## 注意

- 本仓库内容为作者个人 Bot 的公开分享，**不含**密钥、令牌、账号与本机路径；`MEMORY.md` 是清空后的模板，不含任何对话记录。
- 角色与世界观属于游戏《异环》及其权利方，本仓库只包含二次创作的人格提示词与外观素材，请自行判断二次使用范围。
- 没有依赖、没有构建步骤，克隆下来直接读文件即可。
